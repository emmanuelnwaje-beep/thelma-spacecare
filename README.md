# Thelma SpaceCare Services — Website

A responsive static website starter for GitHub Pages.

## Before publishing
1. Open `config.js`.
2. Replace `234XXXXXXXXXX` with the company's WhatsApp number in international format. For Nigeria, use `234` followed by the number without its first `0`.
3. Update service areas in `config.js`.
4. Review all service descriptions and remove any service the company does not offer.
5. Add the real business address, approved photos, email and social media links when supplied.
6. Confirm the company name is available with CAC and the chosen domain registrar before treating it as final.

## Deploy with GitHub Pages
1. Create a GitHub repository, for example `thelma-spacecare`.
2. Upload the contents of this ZIP (not the outer ZIP folder) to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish and open the generated website URL.

## Important
- This is a static website. Booking requests open WhatsApp; no booking is automatically confirmed or stored in a database.
- Customers pay the company after service, as agreed.
- Domain registration and paid hosting are not included in this ZIP.
- The website uses Google Fonts from an external provider; system fonts are used as fallbacks.
- Replace placeholder contact details and add only genuine client-approved photographs and testimonials.
